# نظام إدارة أعضاء نادي الصحفي الصغير

تطبيق ويب بسيط يعمل بالكامل داخل المتصفح لإدارة أعضاء نادي الصحفي الصغير بألوان مستوحاة من الشعار (أزرق، أصفر، أسود، أبيض، أحمر).

## المزايا
- إضافة عضو جديد.
- تعديل وحذف الأعضاء.
- البحث بالاسم أو الهاتف.
- إحصائيات سريعة (إجمالي الأعضاء، النشطين، بانتظار التجديد).
- حفظ البيانات محلياً في المتصفح عبر `localStorage`.

## التشغيل محلياً
بما أنه تطبيق HTML/CSS/JS فقط، يكفي فتح ملف `index.html` مباشرة، أو تشغيل خادم بسيط:

```bash
python3 -m http.server 8080
```

ثم افتح:

`http://localhost:8080`

## جعله متاحاً من أي مكان
يمكن رفع نفس الملفات إلى استضافة مجانية مثل:
- **GitHub Pages**
- **Netlify**
- **Vercel**

بعد الرفع ستحصل على رابط عام يمكنك فتحه من أي جهاز.
