# OBS Python News Package Script

ملف `newsroom_obs_package.py` يجهز لك قالب تغطية صحفية لقناة إخبارية داخل OBS يشمل:

- مشاهد متعددة جاهزة.
- ربط عدة كاميرات (حسب أسماء المصادر عندك).
- Lower Third.
- شريط أخبار (Ticker) يتبدّل تلقائياً.
- ساعة UTC مباشرة.
- لوجو القناة.

## الاستخدام

1. افتح OBS.
2. ادخل إلى: `Tools -> Scripts`.
3. أضف الملف `newsroom_obs_package.py`.
4. من إعدادات السكربت:
   - اكتب اسم القناة.
   - ضع مسار اللوجو.
   - اكتب أسماء مصادر الكاميرات الموجودة عندك بالضبط.
   - اكتب عناصر شريط الأخبار (كل سطر خبر مستقل).
5. اضغط **Build / Update News Package**.

## المشاهد التي ينشئها السكربت

- `01_Studio_Wide`
- `02_Anchor_Close`
- `03_Field_Report`
- `04_Breaking_News`
- `05_Multi_Cam`

> ملاحظة: السكربت لا ينشئ كاميرات جديدة، وإنما يستخدم مصادر الكاميرات الموجودة عندك مسبقاً في OBS حسب الأسماء التي تدخلها.

## ملاحظات

- هذا السكربت مصمم أساساً لـ OBS على Windows لأن مصدر النص المستخدم هو `text_gdiplus`.
- إذا كنت على Linux/macOS يمكن تعديله لاستخدام نوع مصدر نص متوافق.
