# Plantify - تطبيق معرفة حالة النباتات

تطبيق ويب يساعد المستخدم على معرفة حالة النبتة عبر:
- رفع صورة للنبتة.
- تحليل لوني أولي للصورة داخل المتصفح.
- إظهار المشكلة المحتملة وخطوات عملية مقترحة.

## المشكلة التي تم إصلاحها
تمت إضافة ملف تشغيل واضح `app.py` لتجنب مشكلة `not found` عند فتح التطبيق، بحيث يعمل المسار الرئيسي `/` مباشرة.

## التشغيل (الطريقة الموصى بها)

```bash
python app.py
```

ثم افتح الرابط:
`http://localhost:8000`

## فحص الخدمة

```bash
curl http://localhost:8000/health
```

## ملاحظة
هذا تشخيص أولي (MVP) مبني على مؤشرات لونية وليس بديلاً عن خبير زراعي عند الحالات المتقدمة.
